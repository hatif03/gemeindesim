GemeindeSim: a bilingual civic town on Apertus 1.5

Hack Apertus 2026 · Track 2B (own project) · Team hatif03 · 5–15 October 2026 · code, logs and the full research record: track_2b/research, track_2b/docs/research

1. Summary

GemeindeSim reads a Swiss municipal vote in German and French and spawns a small town of residents who talk, move, change mood and form a stance on a pixel-art map; a closing report says who is affected and why, never how to vote. We also used the town as a test bench for Apertus 1.5 (8B and 70B): about 5,000 logged gateway calls in 18 experiments and 30 instrumented simulations. Apertus is an excellent speaker (112/112 residents' lines in the right language; it abstains when a premise is missing; it never gave voting advice in 30 tests). It is an unreliable decider: asked for a stance, every resident said yes (15/15, also with no persona); on 54 real Swiss federal votes the simulated electorate was 34–37 points too favourable and the 8B followed an official recommendation 98 % of the time; both sizes defined Steuerfuss wrongly and failed a one-step percentage. The design follows: the model voices; the application owns the stance, the arithmetic and the sources. Result: valid citations 0 → 99–100 %, invented outcomes in reports 12/30 → 0/30, a town that starts with real disagreement, and residents whose words match their stance (≈ 50 % → ≈ 80 %).

2. Architecture and target deployment

policy text (DE/FR/EN) ─► chunk + BM25 (closed corpus, per-chunk language, ballot question pinned) ─► parse_policy (sectors, impacts, ideological valence) ─► generate_npcs (persona, impact, pro/con arguments in own language) ─► stance = valence×leaning + 0.5×impact − 0.6×computed household cost (code) ─► N rounds (standard or swarm graph): retrieve ─► reflect ─► plan ─► 1–3 typed events (chat/move/protest/mood/price) ─► code: numeral + citation check, DE ß→ss ─► opinion dynamics in Python (bounded confidence; drift only for residents who conversed) ─► Socket.IO ─► Next.js + Phaser (map, stance poll, citations) ─► report (stance poll from code, no outcome, no advice)

Deployability. Two Docker services (FastAPI/LangGraph backend, Next.js frontend); the corpus is a read-only volume; the only outbound call is the OpenAI-compatible endpoint LLM_BASE_URL. Primary (c): Swiss-hosted endpoint (the hackathon gateway now). (a) on-premise / (b) air-gapped: point LLM_BASE_URL at a local vLLM serving swiss-ai/Apertus-v1.5-70B or -8B. Status, honestly: configured and the clean-checkout stack was started and probed; the model behaviours below were measured on the hosted gateway only. No GPU was available, so research/probe_endpoint.py (the same table against any endpoint) is ready for a GPU host and was validated against the hosted 8B. The 8B is about 4× faster per simulation than the 70B and fits modest hardware.

Concurrency is a semaphore of 4 (the gateway answers 429 above ≈ 4 in flight); a 429 is retried on the same model. A reminder paragraph as the last paragraph of the resident prompt binds speech to the code-owned stance; undecided residents get one named pro and one named con argument in new wording.

4. Data

Synthetic bilingual Linden Steuerfuss / school-credit text (data/, plus a balanced variant with the referendum committee's arguments). No personal data. For evaluation only: Swissvotes (Univ. Bern), 54 federal votes 2021–2026 with results; one real Federal Council booklet (28 Sept 2025, 48 pages) downloaded by script, not vendored.

6. Limitations

  • Not a vote predictor (54 real votes; weak signal after bias correction). Stance weights are modelling assumptions, not calibrated; the stance prior produces disagreement and is not evidence that real residents would split that way.
  • Small n: 3–5 simulations per group, 15 residents in population tests, 15 held-out votes; ranges, no significance tests. LLM classifiers (79–91 % mutual agreement) score the speech tests.
  • One endpoint, one day; latency drifts several-fold. Sovereign parity not measured (no GPU). German/French register: native-speaker review pack prepared (docs/review/); status: @@REVIEW@@.
  • Open: price_pressure indicator is always 0; invoke_llm_think is unused; the 8B never emits move; the Linden sample is synthetic and short.

7. Reproducibility

cp track_2b/.env.example track_2b/.env (set LLM_API_KEY), then make run → UI localhost:3000 (second port UI_ALT_PORT, default 8080). Tests: cd track_2b/src/backend && uv run pytest --deselect tests/test_e2e.py (119 offline). Every experiment is a script in research/ with raw call logs in research/results/; docs/research/LAB-NOTEBOOK.md records every decision, including failed attempts. Python 3.12, Docker.
